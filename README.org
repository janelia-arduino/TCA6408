** Description

Arduino interface library for the TI TCA6408 8-bit I2C I/O expander.

See [[./CHANGELOG.md][CHANGELOG.md]] for release notes and
[[./docs/HARDWARE_VALIDATION.md][docs/HARDWARE_VALIDATION.md]] for bench
validation status.

* Quick Start

This library now keeps I2C ownership explicit: your sketch configures and
starts the =TwoWire= bus, and =TCA6408= uses that already-configured bus for
register access.

** Basic setup

#+BEGIN_SRC cpp
#include <TCA6408.h>

TwoWire &wire = Wire;
TCA6408 io_expander;

void setup()
{
  wire.begin();
  io_expander.setup(wire, TCA6408::DEVICE_ADDRESS_0);

  io_expander.setAllPinsInput();
  uint8_t inputs = io_expander.readInputRegister();
}
#+END_SRC

The chip exposes all eight valid addresses:

- =DEVICE_ADDRESS_0= through =DEVICE_ADDRESS_7=
- =0x20= through =0x27=

** Typed I2C results

For code that needs communication status, prefer the typed result APIs:

- =readRegisterResult(register_address)=
- =writeRegisterResult(register_address, data)=
- =getLastI2cError()=
- =communicating()=

Current =tca6408::I2cError= values are:

- =None=
- =NotInitialized=
- =InvalidPin=
- =DataTooLong=
- =AddressNack=
- =DataNack=
- =OtherBusError=
- =RequestFailed=
- =ShortRead=

The legacy helpers remain available for simple sketches:

- =readRegister(register_address)=
- =writeRegister(register_address, data)=

Those wrappers still update =getLastI2cError()=, but they do not surface the
error directly in their return type.

** Reset handling

If the optional reset pin is wired, configure it once and pulse it with
=reset()= when needed:

#+BEGIN_SRC cpp
io_expander.setResetPin(5);
io_expander.reset();
#+END_SRC

** Per-pin helpers

The chip does not provide debounce, per-pin interrupt masking, edge selection,
or output fault readback. It does provide simple port registers, and the library
now exposes per-pin helpers for common masked updates:

- =readInputPin(pin)=
- =clearInterrupt()=
- =pinIsInput(pin)=
- =setPinInput(pin)=
- =setPinOutput(pin)=
- =readOutputRegister()=
- =readOutputPin(pin)=
- =writeOutputPin(pin, value)=
- =setPinHigh(pin)=
- =setPinLow(pin)=
- =pinPolarityInverted(pin)=
- =setPinPolarityInverted(pin)=
- =setPinPolarityOriginal(pin)=

Notes from the datasheet:

- Reading the input port register clears =INT= for the reporting pin state.
- The input port register reflects the actual pin logic level, even for pins
  configured as outputs.
- The output port register reads back the output latch value, not the physical
  pin voltage.

* Interrupt Notes

The interrupt output indicates that an input changed, but the interrupt service
routine should stay short. The recommended pattern is:

- ISR sets a volatile flag.
- Main loop reads the input register and clears application state.

See [[./examples/InterruptRead/InterruptRead.ino][examples/InterruptRead/InterruptRead.ino]]
for a minimal example.

pixi run build examples/PinHelpers pico
pixi run release-check
#+END_SRC

Pixi keeps the =pio= CLI and its Python runtime local to the repository. The
=build=, =upload=, =flash=, and =rebuild= tasks select examples without editing
=platformio.ini=.

Useful commands:

#+BEGIN_SRC sh
pixi run ports
pixi run build examples/PollingRead teensy40
pixi run upload examples/PollingRead pico /dev/ttyACM0
pixi run monitor /dev/ttyACM0 115200
pixi run set-version -- 2.0.0
#+END_SRC
